# PULSE — рост v0.4

**25.10.2026.** Распространяется конкретная игра; удерживает желание сыграть снова с людьми. Воронка считает Game MAU, не регистрации.

## Два канала входа

**Invite-first:** знакомый зовёт в маленькую игру по ссылке. Это дешёвый путь к первой ценности, который не требует общего круглосуточного пула. Но спрос друзей не доказывает ценность знакомства: cohorts friend-invite / stranger-match разделены.

**Новые люди:** одна взрослая языковая когорта, обеспеченные окна, приглашённые ведущие только при необходимости. Три темы живут внутри одного matching pool. Не дробить очередь по каждому настроению/полу/игре.

## Плотность

При условных DAU/MAU=20% и 25 мин/день средний CCU = MAU×0,2×25/1440: 100 MAU →0,35; 1k→3,47; 10k→34,72. Пик ×4 — отдельная гипотеза, не доказательство. Деление на 12 языковых/форматных пулов уменьшает доступность ещё в 12 раз.

Для упрощённого независимого Poisson-поступления вероятность хотя бы одного нового совместимого человека за 2 минуты =1−exp(−λ×2). Для 90% нужно около 69 arrivals/hour в одном пуле. Это не точная очередь: блокировки, согласия, busy и групповой размер повышают потребность.

Invite решает старт знакомой пары; не создаёт неизвестных людей из воздуха. Для 3–4 нужны подтверждения/резерв, не обещание «всегда найдём». Перенос слота не штрафует пользователя.

## Семь экспериментов

| ID | Гипотеза / тест | Основной результат | Ограничение |
|---|---|---|---|
| G1 | Приглашение в конкретный дуэт лучше общей ссылки на приложение | Invite→completed и D7 | Один источник, сопоставимые группы |
| G2 | Короткий оригинальный игровой сюжет в TikTok/Instagram/Shorts приводит игроков | Activated D7 / публикация и труд | Только разрешённый материал, без чужих голосов/ответов |
| G3 | Малый ведущий приводит качественную когорту | S7 и cost/retained player | Нет гарантии по followers; платные тесты только в cap |
| G4 | Общий финал вызывает добровольное приглашение | Invite yield после реальной игры | Не награждать за адресную книгу/массовые рассылки |
| G5 | Повтор с прежним peer повышает return | S7/S28/WRP | Не смешивать с immediate rematch |
| G6 | Взрослый игровой клуб даёт достаточные окна | Completed games и явка | Организатор/труд измеряются |
| G7 | ASO обещание «короткая social game» привлекает нужных | Store→completed→D7 | Только после реального мобильного продукта |

Сначала G1/G6/G5, потом G2/G3. Не запускать семь одновременно. Никаких рассылок от агента без прямого поручения.

## Вирусность без выдуманной экспоненты

Пример: 2 приглашения ×40% открытия ×60% первой завершённой игры ×35% D7 =0,168 retained invitees на активного приглашающего. Это условный расчёт, не измеренный K. Он ниже 1: органика может помогать, но не гарантирует самоподдерживающийся рост.

Открытка делится только допустимым содержимым и по согласию. Нет фальшивых «тебя ждут», FOMO-сезонов и покупки чужого внимания. Paid CAC измерять на **нового активированного**, не на дешёвую установку. Не покупать масштаб при отрицательном contribution.
