# PULSE — PRD v0.4

**25.10.2026 · актуальный продуктовый контракт.** Владелец поручил объединить game-first v0.3 и повторные компании, согласовав документы. Направление авторизовано для планирования; числа и коммерческие гипотезы требуют проверки. Состояние кода — в [README](../README.md).

## 1. Обещание и аудитория

**Приходи за игрой, возвращайся к своим.** За короткую партию взрослый получает удовольствие от живых ответов и совместных решений; при желании продолжает с теми же людьми. Три задачи: развлечься сейчас, узнать нового человека, вернуться к компании. Один цикл: **игра → совместный момент → добровольный повтор → знакомая компания**.

Начальная гипотеза аудитории — взрослые 23–35, которым нравятся лёгкие party games; доступ 18+, верхнего ограничения нет. Один язык и совместимые вечерние часы; город выбирается по реальному доступу к людям. Баку не считается подтверждённым рынком. Флирт — поздняя отдельная добровольная тема, не скрытая цель каждого знакомства.

Web/PWA сначала. Приглашённый друг проходит тот же допуск. Android после стабильной беты; iOS отдельно: игра не является обходом правил random/anonymous chat.

## 2. Этапы

| Этап | Обязательная ценность | Граница |
|---|---|---|
| G0: основание | Воспроизводимая alpha, исправленные ACL/revocation, проект допуска и операций | Не публичный запуск |
| G1: дуэт | 2 игрока, 7 раундов «Угадай меня», текст, результат, rematch, invite, взаимный контакт | Без колеса, спецкарт, покупок, голоса и ленты |
| G2: мини-вечеринка | 3–4 игрока, три типа раундов, равное участие | Колесо только после теста; не блокер |
| G3: свои компании | Добровольный круг ≥3 человек и повторная игра | Без бесконечного группового чата и обязательства дружить |
| G4: расширение | Проверенные voice, host tools, косметика | По одному эксперименту, отдельные gates |

Ручной G2 тестируется до дорогой автоматизации: дуэт — первая техническая вертикаль, не заранее объявленный лучший социальный формат.

## 3. Сценарии

**UC01 — с другом.** Отзываемая invite-ссылка в закрытое лобби; язык, формат, правила; допуск и явная готовность обоих. Ссылка не открывает переписки/профили вне лобби.

**UC02 — с новым человеком.** В объявленное окно сервер проверяет допуск, язык, разрешённые темы и блокировки; атомарно резервирует места; оба принимают предложение. Если людей нет — честное ожидание, invite или следующее окно. Одиночный пример карточки явно учебный, не живая игра.

**UC03 — партия.** Два вводных раунда, четыре раунда узнавания, один общий финал. Каждый скрытно отвечает за себя и прогнозирует другого. Сервер раскрывает ответы одновременно. Skip без штрафа, выйти можно всегда. [Правила](GAME_DESIGN.md).

**UC04 — сейчас.** На результате «Ещё партию» и «На сегодня всё». Новый матч только при явном согласии всех; отказ/молчание не раскрывает причину.

**UC05 — позже.** Отдельное взаимное «Позвать ещё» разрешает ограниченное приглашение на игру. Отдельное «Добавить в знакомые и разрешить личный чат» открывает DM. Для ≥3 совместимых согласившихся можно предложить круг; игра не означает DM со всеми.

**UC06 — остановить контакт.** Leave/mute/block/report на каждом экране. Block закрывает дуэт; в группе блокирующий немедленно перестаёт получать взаимодействие заблокированного и выходит с нейтральным сообщением. Других не выбрасывает из чужих матчей. Ban/logout/deletion отзывают чтение и отправку.

## 4. Требования и приёмка

| ID | Этап | Требование | Доказательство |
|---|---|---|---|
| FR-01 | G0 | Auth/18+/ban на сервере | Dev identity невозможно включить в production |
| FR-02 | G0 | ACL и отзыв | Чужой ID не закрывает матч; logout/ban/block прекращают входящие события |
| FR-03 | G1 | Invite/очередь | Нет двойного места; истёкшие ссылки/offer не допускают; cancel scoped |
| FR-04 | G1 | Скрытые ответ/прогноз | Нет чужих секретов до reveal, включая host и reconnect |
| FR-05 | G1 | Серверные состояния | Таймер, переходы, scores и end; один результат |
| FR-06 | G1 | Свободный раунд | Skip без штрафа; timeout не сочиняет ответ |
| FR-07 | G1 | Reconnect | Snapshot, cursor replay, ACK; без повторных очков |
| FR-08 | G1 | Текст/реакции | Plain text, лимиты, report; без ранних ссылок/вложений |
| FR-09 | G1 | Три согласия | Rematch, будущая игра, контакт/DM разделены; race-safe revoke |
| FR-10 | G1 | Контент/аналитика | Версии карточек, редактор, события без ответов |
| FR-11 | G1 | Доступность | Клавиатура, screen reader, reduced motion; скорость не даёт очков |
| FR-12 | G2 | Группа 3–4 | Равные очереди; корректный выход; host не системный модератор |
| FR-13 | G3 | Повторная компания | ≥3 opt-in; нет автоприглашений/DM или раскрытия отказов |
| FR-14 | G4 | Voice | Opt-in, revoke, расходы и текстовая альтернатива |

## 5. Убрать и отложить

Не строить независимые Text Match/Voice Match продукты, feed, офлайн, глобальный каталог комнат, 3D-мир и десятки мини-игр. Текст обслуживает игру; голос может улучшить доказанный опыт. Убрать обидные титулы, романтические рейтинги и streak-бонусы за угадывание. Skip никогда не ресурс.

Не обещать паритет; balanced очередь не входит в пилот. Нет покупки побед, внимания, доступа к полу или скрытых AI-игроков.

## 6. Готовность и решения

Локальная G1: два синтетических клиента через реальный сервер проходят допуск → invite/подбор → 7 раундов → результат → взаимный rematch; третий не читает секреты и не управляет матчем. Отдельно timeout, дубль, block/revoke race, reconnect, выход и восстановление 100+ сообщений.

Живой пилот: страны/age route, оператор и резерв, редактор, жалобы/удаление, ограниченные часы, закрытые критические дефекты. Prototype и зелёный research spike этого не доказывают.

[METRICS](METRICS.md) определяет знаменатели и gates, [ROADMAP](../ROADMAP.md) — зависимости, [BUSINESS_PLAN](BUSINESS_PLAN.md) — ресурсы. Если удовольствие зависит от ведущего, его труд — часть стоимости, а не бесплатный скрытый ресурс.
