# PULSE v0.4 — матрица референсов и собственных решений

**25.10.2026.** Имя файла сохранено для ссылок. Это больше не backlog клона Litmatch: основной продукт — игра и возвращение к компании.

| Референс / класс | Полезный принцип | Решение PULSE | Не переносить |
|---|---|---|---|
| Litmatch: быстрый контакт | Мало действий до другого человека | Invite/ограниченный подбор сразу в игру | Самостоятельную текстовую рулетку как весь продукт |
| Plato: games + chat | Игровая ценность существует сама | Один сильный социальный игровой цикл | Каталог десятков игр и конкурентные ранги в MVP |
| WePlay / Hago: party/voice | Общий предмет действия | Мини-вечеринка после дуэта; voice по доказанной нужде | Донатное давление, 3D, сложные коллекции |
| TopTop: игры и компания | Возвращение к совместному досугу | Повтор с тем же составом и circle | Копирование настольных игр/ассетов |
| Spin the Bottle | Понятная случайность и ожидание | Колесо только для типа безопасного раунда | Принудительный романтический контакт/рейтинг подарков |
| Timeleft / BFF / Discord | Компания и координация | Ограниченное приглашение/следующая встреча | Офлайн-логистику и огромную структуру сообществ |
| Slowly | Не соревноваться внешностью | Псевдоним, право молчать/пропускать | Долгое ожидание как обязательную механику |

Источники и ограничения — [MARKET_COMPETITORS](strategy/MARKET_COMPETITORS.md). Форматы и правила — [PRD](PRD.md), [GAME_DESIGN](GAME_DESIGN.md). Названия/графику/код/тексты чужих карточек не копировать.

## Соответствие старых поверхностей

Text Match → вход в игровую сессию и внутриигровой текст.
Voice Match → самостоятельный продукт убран; optional voice внутри игры позже.
Party Rooms → компактные 3–4 после ручного теста.
Connections → знакомые по взаимности; game invite и DM различаются.
Feed/Moments → нет в обозримом roadmap.
Outings → вне текущего продукта, без даты.
Avatar → несколько оригинальных абстрактных вариантов; косметика после спроса.
