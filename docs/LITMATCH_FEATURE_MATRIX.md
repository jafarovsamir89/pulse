# Litmatch → PULSE: матрица функционального аналога v0.2

**Дата:** 21.10.2026. Источник функций: [официальное описание Litmatch в Google Play](https://play.google.com/store/apps/details?id=com.litatom.app) (обновление 09.09.2026). Это **продуктовый референс**, не спецификация его закрытых алгоритмов. Мы не знаем серверную реализацию Litmatch, его конверсии и текущий CCU.

## Навигация

Нижние вкладки (авторский UI): **Общение** (Text Match + Voice Match), **Комнаты**, **Моменты** (P2), **Связи**, **Профиль**. Не показывать пустую вкладку Moments в P0; в раннем MVP достаточно «Найти собеседника», «Комнаты», «Связи», «Профиль».

## Поведение Text Match v0.2 (P0)

- После age gate и короткого профиля нажать «Найти собеседника», выбрать язык, при желании настроение/тему.
- Сервер проверяет доступ, ограничения, блокировки, одновременные сессии, rate limits. Отдельный TTL сессии ожидания, идемпотентные повторы.
- Только **реальный, добровольно доступный** собеседник; взаимный handshake на короткую текстовую сессию. Не создавать «демо-пользователей» в production.
- Пока оба в короткой сессии — чат и стартовый prompt; любой может завершить раньше. Сервер скрывает приватные данные и применяет правила репортов.
- Завершение диалога не отправляет автоматический DM: оба выбирают «Остаться на связи» → взаимный контакт; иначе сессия удаляется согласно retention.
- Без людей: честная очередь и выбор вернуться позже/перейти в открытую текстовую Party Room по согласию.
- **Нет обязательных персональных фотографий, указания дохода, ссылки на соцсети, выбора партнёров за деньги, видео, рейтинга внешности.**

## Поведение Voice Match и Party Rooms (P1)

- Voice Match: отдельное разрешение микрофона и серверный scoped RTC token; при отключении, блокировке, бане токен не возобновляется. Без записи голоса по умолчанию.
- Party Rooms: темы, реальная вместимость, создание хостом (ограниченное), вход по серверному ACL, текст, список актуальных участников, mute, kick/report, очередь микрофона и добровольная категория balanced/open. При нехватке 50/50 нет искусственной подмены и нет тихого перевода в open.
- До открытия публичного голоса обязателен работающий модераторский процесс и измеренные расходы на participant-minutes.

## Отдельные продуктовые риски

1. **Apple Store:** Apple App Review Guidelines §1.2 (редакция 2026) прямо указывает приложения, используемые преимущественно для случайных/анонимных чатов, среди потенциально недопускаемых. Группы и возрастное ограничение **не гарантируют** апрув. Первые платформы Web/PWA и Android после compliance проверки; iOS — отдельное go/no-go.
2. **Google Play:** для core anonymous/random interaction применимость возрастных ограничений и policy проверить отдельно; одного чекбокса «Мне 18» может быть недостаточно.
3. **Пол/гендер:** реальный 50/50 зависит от opt-in supply; не обещать вечного паритета, не ограничивать общие комнаты.
4. **Концентрация рынка:** быстрому матчу нужна высокая плотность онлайн. Поэтому тестируем одну языковую группу и часы пик, а не глобальный 24/7 с первого дня.
5. **Модерация:** быстрое 1:1 общение повышает нагрузку на жалобы и антиабьюз; нельзя включать публичный матчинг без блокировок.
6. **Юридическая чистота:** только clean-room реализация собственными исходниками и оригинальными дизайн-ассетами.
