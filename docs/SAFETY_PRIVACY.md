# PULSE — защита пользователей, анонимность, приватность (v0.2 addendum)

**Версия 0.1, 21.10.2026.** Черновые проектные требования, **не опубликованная политика конфиденциальности или Terms of Service**. Перед публичным запуском обязателен юридический и platform-policy review.

## Основная модель угроз

| Угроза | Почему вероятна | Контроль до беты |
|---|---|---|
| Несовершеннолетний внутри 18+ комнат | формальная галочка легко обходится | age-gating, риск-ориентированная проверка, жалоба «возможно несовершеннолетний», быстрое ограничение доступа |
| Домогательство и повторный контакт | псевдонимы + быстрый вход | block/mute/leave, no unsolicited DM, исключения в матчинге, админ-панель |
| Вымогательство денег / ссылки | люди уязвимы к social engineering | антиспам, предупреждения, жалобы «просит деньги», ограничение ссылок/рекламы |
| Деанонимизация | раскрытие фото/IP/телефона/локации | профили без обязательного фото, server-side ACL, city-level location, минимальные логи |
| Фейковые аккаунты и рейды | низкий барьер вступления | rate limit, anti-abuse, устройства/сессии с оценкой риска, без слежки за всеми по умолчанию |
| Репорты как месть | ошибочные блокировки | независимый review, человеческая апелляция, журналы решений, без публичных оценок |
| Неприятный офлайн-инцидент | физическая безопасность | **нет открытых офлайн-встреч в MVP**; проверенные хосты и публичные места позже |
| Сексуальный/насильственный контент | UGC audio/text | чёткие правила, фильтрация, репорты, быстрое отключение нарушителя |

## Анонимность не равна безнаказанности

- Другим пользователям видны псевдоним, необязательный шаблонный аватар, язык и явно выбранные интересы.
- Персональные данные аутентификации и сигналы злоупотреблений доступны только уполномоченным сервисам/сотрудникам, не участникам комнаты.
- Для P0 аккаунта — минимум подтверждения возраста/согласия; для хоста офлайн-встреч дополнительные проверки по риску. Конкретный провайдер и законность требований выбираются перед релизом.
- Не хранить копии паспортов/селфи без доказанной необходимости и юридически согласованного провайдера. Никакого публичного «verified girl / boy».

## Возраст и магазины

Продукт предназначен строго для 18+. Google Play вводит возрастные ограничения для приложений со случайным/анонимным общением; App Store §1.2 особо указывает на риск Chatroulette-style, случайного и анонимного чата. Никакая формулировка в маркетинге не гарантирует прохождения ревью. **v0.2 pivot:** быстрый Text Match 1:1 — важная функция, которая повышает policy-риск. Нельзя считать её безопасной для iOS только из-за наличия тематических комнат; запуск Web/PWA, Android после policy review, iOS без гарантии. Источники: `RESEARCH.md`.

## Сообщения и голос

- Только члены комнаты могут отправлять/читать сообщения; контент фильтруется от явно запрещённого и от спама.
- В MVP личные сообщения от незнакомцев отключены. Позже личный контакт только по взаимному согласию.
- Пользователь контролирует микрофон; разрешение запрашивается непосредственно перед входом в голос. При невозможности аудио остаётся текст.
- **Не записывать голос по умолчанию.** Репорты на голос разбираются по доступным сигналам и показаниям, нельзя обещать доказательства, которых не существует. Любая будущая запись требует отдельного правового основания, явного прозрачного согласия и retention.
- Нельзя играть коммерческую музыку через сервер без прав на публичное воспроизведение/трансляцию; для MVP — текст/простые игры или лицензированный контент.

## Безопасность данных и предлагаемый retention

**Предложения, требующие проверки закона и DPIA/оценки рисков:**

| Данные | Предварительная политика |
|---|---|
| Email/auth identifier | пока действует учётная запись; шифрование/ограниченный доступ |
| Сообщения комнаты | по умолчанию удалять после 7 дней, кроме законно сохранённых доказательств жалоб |
| Presence/очереди | только время жизни сессии + короткий TTL |
| Агрегированная аналитика | обезличенная, без содержимого переписки |
| Репорты и санкции | до 90 дней или дольше по законному основанию/спору; ограниченный доступ |
| Аудио | не записывается по умолчанию |
| Геолокация | только город с явным согласием на будущие встречи, не GPS |

Эти сроки НЕ утверждены юридически; предусмотреть экспорт/удаление данных и законные исключения. Данные, нужные для безопасности, минимизировать и не использовать в рекламе.

## Обязательные механизмы до беты

1. `Report`: контекст, категория, безопасное подтверждение и очередь модератора.
2. `Block`: немедленно действует на DM и будущий матчинг, в активной комнате доступен выход/мут; исключения «оба в комнате» надо решить без утечки действия блокировавшего.
3. `Mute`: локальное скрытие/отключение, серверное ограничение за нарушение.
4. `Leave`: участник покидает комнату без необходимости объяснения.
5. `Moderator Console`: репорты, расследования, временные баны, отмена санкций и audit.
6. `Appeal`: канал обжалования, человеческий review критичных случаев.
7. `Contact`: опубликованный адрес/форма поддержки, время ответа и эскалация угроз.
8. `Rate limit`: сообщения, создания аккаунтов, приглашения, репорты, повторные join.
9. `Privacy`: отзыв согласия, удаление аккаунта, честные disclosure при исключениях.

### Операционные ориентиры реакции (не обещание SLA)

- **P0 непосредственная угроза:** модератор немедленно ограничивает доступ при подтверждённом сигнале; целевой response ≤15 минут во время дежурства.
- **P1 угрозы/домогательства:** первичное рассмотрение ≤2 часа во время активных мероприятий.
- **P2 обычный спам:** в течение 24 часов.

Пока нет дежурного персонала и проверенных сценариев, не открывать публичные голосовые комнаты 24/7 и не обещать круглосуточный мониторинг. Локальные экстренные службы — вне приложения, если ситуация опасна.

## Группа и гендер

- Пол/гендер — **не публичный рынок** и не основа монетизации.
- Любой совершеннолетний имеет равный доступ к открытым комнатам, вне зависимости от пола, ориентации, гендера или дохода.
- Добровольный 50/50 режим создаётся только при достаточном наборе двух бинарных self-described групп. Пользователь видит честное ожидание. Нет гарантии точного паритета и нет требований предъявить лицо/паспорт для проверки гендера.
- Не использовать чувствительные сигналы в рекламном таргетинге или публичной статистике; делать bias-аудит, не показывать сегменты с маленькой выборкой.

## Офлайн-встречи: отдельная фаза

Только после беты, договорённостей с хостами и проверки юрисдикции: публичные места, ограниченная группа, проверка организатора, предупреждение не делиться домашним адресом, возможность уведомить доверенного человека, политика отмены, жалобы и реакция на инциденты. Организатору нельзя публиковать точный адрес частной квартиры для незнакомых людей.

## Красные линии

Не имитировать пользователей ботами, не объявлять fake-online, не скрывать коммерческие интересы организатора, не продавать доступ к участникам, не делать профили с рейтингом красоты, не требовать фото или микрофон для обычного текстового участия, не скрывать условия хранения данных. Любая критическая уязвимость доступа → остановка пилота до исправления.


## v0.2 — дополнительные ограничения для Text Match и Voice Match

- **До парного матча:** admission 18+ по применимому provider/policy, не иметь текущего бана, blocklist exclusions **в обе стороны**, rate-limit повторных поисков и сообщений. Нельзя «выбрать девушку за деньги».
- **На этапе Text Match:** no unsolicited DM; chat permission только для двух подтверждённых members текущей сессии; жёсткий TTL для offer, одно active matching состояние на аккаунт, неизменяемый audit trail модератора.
- **После матча:** сохранение контакта требует **двух opt-in**; отказ без уведомления о причине, block прекращает DM и запрещает повторный матч.
- **Контент:** ограничения ссылок, телефонных номеров, повторяющихся финансовых просьб и спама с человеком в контуре апелляций. Не объявлять любое обсуждение денег нарушением без контекста, но противодействовать выманиванию средств.
- **Voice Match / Party:** отдельный consent на микрофон; RTC revocation; безопасность голоса до публичного 24/7 запуска должна быть операционно обеспечена модерацией и быстрым реагированием. Никакой фоновой записи.
- **Проверка платформ:** актуальная Apple §1.2 отдельно относит random/anonymous chat к рискованным/неподходящим для App Store категориям. Даже «topic-first» не гарантирует одобрения. Никаких способов обхода review.
