# PULSE — безопасность и приватность v0.4

**25.10.2026 · проект требований, не опубликованная юридическая политика.** Игра с незнакомцами сохраняет UGC/возрастные риски. Платформа 18+, но это не разрешение на сексуальное давление.

## Обязательное до живого цифрового пилота

Реальные auth/admission; определённые страны и путь проверки возраста; понятные правила; server-side bans/blocks/ACL/revocation; leave/report/mute; ответственный человек и резерв; incident drill; каналы поддержки/апелляции; редактура карточек; data map, удаление и restore. Dev identities только в изолированном local/test, не в live.

Оператор объявляет обеспеченные часы. Нет возможности реагировать — новые stranger-сессии закрываются. Основатель может вести ограниченные окна; Codex не считается дежурным человеком. Приватные игры также требуют поддержки и защищённого допуска, не являются обходом правил.

## Согласия и действия

| Действие | Что разрешает | Чего не разрешает |
|---|---|---|
| Ready/start | Конкретный матч и допустимые темы | Микрофон, флирт, DM, публичный шаринг |
| «Ещё партию» | Новый матч с согласившимся составом | Постоянное общение |
| «Позвать ещё» взаимно | Ограниченное будущее game invite | Свободные сообщения |
| Контакт + DM взаимно | Отзываемый личный текстовый канал | Голос, раскрытие данных |
| Войти в круг | Участие/приглашения этого круга | DM со всеми, публичный статус дружбы |
| Voice opt-in | Микрофон в данном контексте | Запись/публикация |
| Поделиться карточкой | Только явно согласованный результат | Чужие ответы/голос/идентификаторы |

Нет публичного счётчика симпатий. Отказ не требует объяснения. Block закрывает дуэт; из группы блокирующий безопасно выходит и прекращает получение взаимодействия, без раскрытия причин. Других участников не отключает от чужих игр. Отзыв контакта и block действуют на новые sends/fan-out после серверного commit.

## Игровые угрозы

- Секретный ответ может утечь через snapshot/reconnect/host/logs: отдельные DTO, тест третьим клиентом.
- Блеф не означает обязанность рассказывать личное: разрешены выдумки, нейтральные темы, skip.
- Очки/бейджи не ранжируют привлекательность или качество человека. Обидные титулы исключены.
- Эхо использует только добровольно раскрытые нейтральные события текущей игры; не строить психологический профиль.
- Нет скрытых миссий выманить контакт, включить микрофон или добиться флирта.
- Реакции ограничены; host управляет ритмом, а не системными санкциями. Месть через репорты требует review.
- Нет денежных ставок, loot boxes, платных побед, покупки внимания или автоматических AI-собеседников.
- Фото/вложения/внешние ссылки в раннем игровом чате ограничены; текстовые фильтры не заменяют человека.

## Возраст, магазины, юрисдикция

[Apple §1.2](https://developer.apple.com/app-store/review/guidelines/) ограничивает преимущественно random/anonymous-chat продукты; добавление игры не гарантирует одобрение. [Google age-restricted functionality](https://support.google.com/googleplay/android-developer/answer/16302250) требует соответствующих ограничений доступа minors. Перед submission проверить текущую применимость UGC/child safety/billing. Web также подчиняется местным законам.

Выбор оператора, стран, провайдера возраста и законных оснований ещё открыт. Минимизировать age evidence; не хранить документы/биометрию у себя без необходимости. Гендер не верифицировать биометрией и не продавать. Подробнее и источники: [policy review](strategy/TRUST_SAFETY_REVIEW.md).

## Данные: рабочее предложение для проверки

| Данные | Проект жизненного цикла |
|---|---|
| Secret answers/guesses | Нужны для матча/replay, удалить в течение 24 часов после завершения; минимальное lawful evidence по отдельной жалобе |
| Игровой чат | Предложение до 7 дней, затем удаление; срок не юридически утверждён |
| Card exposure IDs | До 28 дней для предотвращения повторов, без ответов; удаление по аккаунту |
| Consent / связь | Пока действует разрешение; отзыв и минимальный audit по обоснованной политике |
| Репорты / санкции | Рабочий ориентир 90 дней, legal hold отдельно с ограниченным доступом |
| Analytics raw pseudonymous events | Рабочий ориентир 90 дней, затем агрегаты с подавлением малых групп |
| Возраст / auth | Минимум provider reference/status; сроки/удаление зависят от выбранного маршрута |
| Voice | Не записывается; никаких обещаний восстановить разговор |

Это проект, не выполненный retention. Утвердить законный lifecycle до реальных данных; TTL поле без worker не удаляет записи. Deletion охватывает ответы, переписку, analytics IDs, backups/restore suppression и lawful exceptions. Экспорт/доступ не раскрывают чужие секреты.

## Ответ на инцидент

Во время окон оператор принимает критический сигнал сразу; проверяет, ограничивает доступ, сохраняет минимальное законное evidence, эскалирует по правилам. Плановые ориентиры: критический triage ≤15 минут в дежурство, обычная жалоба ≤24 часов; это не публичное обещание без staffing. За пределами окон ясно показывать доступность поддержки, не писать «24/7».

Без готового маршрута угроз/несовершеннолетних/шантажa нет stranger-пилота. Тестировать синтетически, не создавать реальные опасные ситуации. Поле отчёта о безопасности отделено от продуктовой аналитики и коммерческих метрик.
