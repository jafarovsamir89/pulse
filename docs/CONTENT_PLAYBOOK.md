# PULSE — контентный процесс v0.4

**25.10.2026.** Контент — часть игрового продукта и постоянная статья расходов. Не публиковать генерацию Codex напрямую в live.

## Карточка как производственная единица

Поля: id/version, оригинальный автор/редактор, язык, тема, тип, текст, 2–3 варианта, follow-up, safety flags, допустимый формат/темп, источник прав, статус review, дата изменения. Не хранить приватные пользовательские ответы как источник новых колод.

Путь: идея → оригинальный текст → review безопасности/тона/прав → тест понимания → ручная игра → limited rollout → архив/исправление. Автор не подтверждает собственную проверку качества как независимую. Для перевода нужен человек, понимающий язык/культуру; машинный перевод недостаточен для шуток и границ согласия.

Первые 24 карточки для исследования; 60–100 для G1 после редакторской проверки. Три темы внутри одного пула. Цель обновления — устранять скуку и неоднозначность; недельная норма не оправдывает плохое содержание.

## Редакторские правила

Хорошая дилемма имеет 2–3 достойных варианта, понятна без биографии, не требует интимной правды и даёт повод удивиться. Не задавать вопросы с очевидно социально желательным ответом («добрый или жестокий»). Не считать отсутствие остроумия поражением.

Исключить из случайной колоды травмы, диагнозы, сексуальные подробности, финансовое положение, точное место, идентифицирующие признания, оскорбления и задания в реальном мире. История может быть выдуманной; «докажи» недопустимо. Тема флирта не входит в стартовую тройку.

| C06 | Юмор / 3 выбора | Робот-друг слишком буквально понимает: «будь проще», «не теряйся» или «поймай настроение» — какая сцена смешнее? |

Это черновые примеры, не уже одобренные карточки. Проверить понятность особенно C06–C08; если участники чаще обсуждают формулировку, чем выбор, упростить.

## Новизна и повтор

Не повторять карточку внутри партии. Для текущего состава учитывать только минимальный список card IDs последних партий; не профиль ответов. Если свежих разрешённых карточек недостаточно — честно предложить другую колоду/повтор, не обещать бесконечную уникальность. Память показов имеет ограниченный срок и входит в deletion.

Эхо связывает две нейтральные карточки внутри одной партии по явному событию; редактор заранее проверяет переходы. Нет inference личности или использования интимных данных.

## Контроль качества

Для каждой версии: доля skip, непонятных формулировок, выходов после показа, spontaneous reply, время раунда, жалобы. Высокий skip не автоматически плохая карточка: смотреть контекст/язык. Жалобу нельзя подавлять ради retention.

Скрытие карточки оператором сразу прекращает новые показы; уже показанное не исчезает из доказательства жалобы. Версия и причины сохраняются с ограниченным доступом. Готовность релиза: права понятны, review пройден, локализация проверена, rollback возможен.

## Бюджет

Плановая единица для модели: 20 минут оплачиваемой редакторской работы на принятую карточку по $30/час; не рыночная котировка и не обещание достаточности. На 60–100 карточек это $600–1 000, либо 20–33 часа основателя с той же альтернативной стоимостью. Локализация и сложные пересмотры сверх этого. В масштабной модели контент выделен отдельно; не считать его бесплатным результатом AI.
