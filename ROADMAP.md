# PULSE — Roadmap v0.2 (Litmatch-подобная социальная модель)

**21.10.2026.** Сроки примерные и зависят от безопасности и размера команды. Этапы выполняются последовательно; не обещать дату релиза до оценки рисков.

## S0 — подтверждение гипотез / 1–2 недели
- [ ] Проинтервьюировать 15–25 совершеннолетних из одной языковой аудитории (например, RU/AZ в Баку).
- [ ] Проверить сценарии Text Match / Party Rooms с 10–20 реальными тестировщиками, модератор присутствует.
- [ ] Отдельно проверить age gate, законодательство, политику Apple/Google, риски UGC/voice.
- [ ] Перерисовать старый прототип v0.1 под главный экран Text Match.
- [ ] Утвердить MVP PRD v0.2, source of truth: `docs/PRD.md`.

**Gate:** понятен спрос на быстрый разговор; ответственная команда модерации и минимум безопасности определены.

## S1 — Text Match Alpha / ориентир недели 3–6
- [ ] pnpm workspace: React PWA + NestJS API + Prisma/Postgres + Redis + Socket.IO.
- [ ] Auth/18+, профиль-псевдоним, язык, базовый avatar preset, правила, delete account.
- [ ] **Реальный быстрый Text Match 1:1**: queue/TTL, server-side reservation/handshake, атомарность, блокировки, честная пустота.
- [ ] Короткий text session/chat, rate-limits, prompt, leave/report; взаимное сохранение и DM только после двух согласий.
- [ ] Модераторский RBAC, audit, доступные жалобы и блокировки.
- [ ] CI unit/integration/E2E: double-match race, age gate, abuse, ACL/IDOR, no fake users.

**Gate:** два человека с отдельных клиентов завершают сквозной безопасный матч и взаимный контакт; нет известных критических safety/ACL дефектов.

## S1.5 — текстовые Party Rooms / ориентир недели 6–8
- [ ] Тематические комнаты 4–6, реальные участники и открытая вместимость.
- [ ] Ведущий, starter prompts, жалобы и leave, никаких поддельных счётчиков.
- [ ] Опциональный balanced 2/2 или 3/3 (только при реальном наборе; open всегда доступен).
- [ ] Исследовать время ожидания, женскую/мужскую удовлетворённость, жалобы, пустые часы.

**Gate:** безопасный воспроизводимый текстовый групповой опыт.

## S2 — Voice Match и Voice Party / ориентир недели 8–12
- [ ] LiveKit/WebRTC, явное opt-in, scoped tokens, mute/kick/revocation, нет записи по умолчанию.
- [ ] Короткие голосовые пары с тайм-аутом; очередь микрофона, ведущий, привилегии модераторов.
- [ ] Реальные затраты participant-minutes, нагрузочное тестирование; staffed moderation.
- [ ] Android-клиент после закрытой проверки Web/PWA, при соблюдении Google Play policy.

**Gate:** безопасность, операционная модерация и unit economics подтверждены; бета с 100–300 участниками, анализ D1/D7.

## S3 — Moments (по фактическому спросу, не раньше беты)
- [ ] Минимальная текстовая лента интересов/моментов, защищённая UGC moderation.
- [ ] Никаких публичных рейтингов внешности, платной видимости, спамных фото.
- [ ] A/B: повышает ли это повторное общение, или лишь создаёт модераторскую нагрузку?

## S4 — прогулки и вечеринки офлайн (только отдельная программа безопасности)
- [ ] City opt-in, публичное место, подтверждённый организатор, cancel/support/incident handling.
- [ ] 3–5 модерируемых пробных встреч; отдельный юр. и safety gate.

## S5 — масштабирование и бизнес
- [ ] Дополнительные языки и города **после** плотности трафика в одном сегменте.
- [ ] Нейтральные кастомизации/инструменты организатора при доказанном спросе; не продаём внимание.
- [ ] iOS — отдельный policy feasibility review: нет гарантии допуска случайных/анонимных чатов.

**Не делать:** видеорулетку, gifts/DIAMOND, платный gender filter, массовые DM, AI под видом людей, бессрочный музыкальный стриминг без лицензий.
