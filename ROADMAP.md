# PULSE — ROADMAP

**Версия:** 0.1, 21.10.2026. Сроки — недели **после начала реализации**, не обещания релиза. Оценка для 1–2 разработчиков при помощи AI и отдельных ресурсов на модерацию.

## S0 — Discovery, правила, подготовка (недели 1–2)

- [ ] 15–25 интервью с совершеннолетними из выбранной языковой группы.
- [ ] 3–5 вручную организованных и модерируемых пробных вечеров.
- [ ] Выбор одной стартовой когорты (предварительно Баку, один язык), целевых часов активности.
- [ ] Оценка правил магазинов, возраста, privacy, авторских прав на музыку; юридическая проверка.
- [ ] UX-исследование прототипа, event taxonomy, CI, проектирование БД.

**Gate S0:** минимум 60% опрошенных участников *пилотного вечера* говорят, что хотели бы повторить опыт; серьёзные риски оформлены в план. Это гипотеза, не статистика рынка.

## S1 — Рабочая текстовая alpha (недели 3–5)

- [ ] Monorepo, API NestJS, Prisma + PostgreSQL, Redis; Web/PWA React.
- [ ] Возрастной gate 18+ и аккаунт, псевдоним, язык, настройки приватности.
- [ ] Календарь тематических событий, комнаты вместимостью 4–6, честная очередь.
- [ ] Подбор по языку/времени/теме; опциональные смешанные комнаты с целевым 50/50, без принудительной смены режима.
- [ ] Авторизованный WebSocket чат, переподключение, уход, текстовые импульсы.
- [ ] Репорты, блокировки, mute, панель модератора, audit log, rate limits.
- [ ] Инструментация метрик, E2E и security-тесты.

**Gate S1:** живые комнаты с 4–6 тестировщиками, 0 известных критических дефектов доступа и блокировок, понятный обработчик пустого набора.

## S2 — Голос и доверие (недели 6–8)

- [ ] LiveKit по короткоживущим токенам, отдельное согласие на микрофон, без записи по умолчанию.
- [ ] Управление микрофоном/выходом/киком; моментальная блокировка и жалоба.
- [ ] Взаимное сохранение контактов после вечера, отсутствие свободного unsolicited DM.
- [ ] Обработка сетевых сбоев, нагрузочные прогоны на 50–100 одновременных пользователей.
- [ ] Оценка затрат на WebRTC participant-minutes и работу команды модерации.

**Gate S2:** защищённый голос в закрытой группе, активная модерация и измеренные расходы.

## S3 — Закрытая бета (недели 9–12)

- [ ] 100–300 участников 18+; фиксированные вечерние окна, реальные хосты.
- [ ] Честные приглашения на конкретное событие, очереди, сегментная аналитика.
- [ ] Измерения D1, D7, качественного времени, жалоб и взаимных контактов.
- [ ] Отчёт Go / Iterate / Stop с причинами и стоимостью обслуживания.

**Gate S3:** KPI из `docs/METRICS.md`, нет критичных невыполненных safety требований. При провале — улучшение или остановка, не рекламный масштаб.

## S4 — Офлайн-встречи (условно недели 13–18, только после S3)

- [ ] Явный opt-in, city-level location, публичные точки; никаких частных домашних адресов.
- [ ] Проверка организаторов по риску, подтверждение участников, отмены и жалобы.
- [ ] Пробные 3–5 городских встреч в небольших группах, присутствие хостов.
- [ ] Юридическая оценка ответственности, охраны данных и местных требований.

**Gate S4:** управляемая безопасность и повторное участие.

## S5 — Масштабирование (после product-market fit)

- [ ] Android-клиент/публикация; расширение географии и языков.
- [ ] Необязательные премиум-инструменты организатора, **никогда продажа доступа к собеседникам**.
- [ ] iOS feasibility review по актуальным правилам Apple и продукту, который не сводится к анонимной рулетке.

## Отложено

Видеорулетка, фото-оценки, бесконечная лента, платные подарки, донаты собеседникам, музыкальный стриминг без лицензии, закрытые квартирные встречи, AI-пользователи, масштабный 3D-мир.
