## Definition of Done

- [ ] Пользовательский сценарий, отрицательные случаи и критерии приёмки описаны.
- [ ] Сервер проверяет возраст, права, блокировки, состояние комнаты.
- [ ] Тесты успешного/ошибочного потока, нагрузки/гонок, безопасности.
- [ ] Аналитика и метрики не раскрывают личные тексты и точную геолокацию.
- [ ] UI не притворяется, будто демонстрационные люди существуют онлайн.
- [ ] CI зелёный, review проведён, нет секретов и P0 уязвимостей.

**Приоритет:** безопасность → качественная группа → измерения → голос → офлайн → деньги.
