# GitHub — публикация и обновление PULSE

Основной репозиторий: https://github.com/jafarovsamir89/pulse

## Рабочий процесс

1. Клонировать проект: `git clone https://github.com/jafarovsamir89/pulse.git`.
2. Создать отдельную ветку задачи: `git switch -c feat/имя-задачи`.
3. Выполнить изменения, запустить `npm test` (пока это только тесты исследовательского matching-модуля).
4. Сделать осмысленный коммит, отправить ветку и открыть Pull Request.
5. Проверить результаты CI и провести код-ревью до слияния в `main`.

Не публикуйте токены, секреты, персональные данные тестировщиков или скрытые ключи в репозитории. Для окружений используйте секреты GitHub Actions либо отдельный secrets manager.

`prototype/index.html` — автономная UX-демонстрация, **не** онлайн-приложение. `spikes/` — экспериментальная логика подбора, **не** безопасный production-сервис. Основные требования находятся в `docs/PRD.md`, задачи — в `TODO.md`.
