# PULSE — люди без масок

> **Статус: pre-MVP / 21 октября 2026.** Production-приложения и сервера пока нет. Репозиторий содержит продуктовую документацию, автономный UX-прототип и экспериментальную модель группового подбора.

**PULSE** — социальное пространство 18+ для людей, которые хотят провести вечер в компании: поговорить, поиграть, послушать музыку, отдохнуть и впоследствии организовать безопасную прогулку или встречу. Не лента статусов, не витрина богатства и не продажа внимания.

## Обещание

**«Зашёл один — провёл время вместе».** Мы не гарантируем моментальных друзей или всегда 50/50. Вместо свайпов и анкет — малые тематические группы и совместные вечерние занятия.

## Принципы

1. **Псевдоним по умолчанию.** Фото, фамилия, работа, автомобиль, социальные сети не требуются. Проверки безопасности платформы не раскрывают личность другим пользователям.
2. **Без продажи внимания.** Никаких платных личных сообщений, дорогих подарков, аукционов за популярность, рейтинга внешности или платного выбора пола.
3. **События, а не свайпы.** Тема, игра, совместный «импульс» и дружеское общение.
4. **Добровольные сбалансированные комнаты.** Цель 50/50 для участников, добровольно выбравших «мужчина»/«женщина», в отдельных комнатах; никакой ложной гарантии общего паритета. Открытые комнаты доступны независимо от пола/гендера.
5. **Безопасность с первого дня.** 18+, жалобы, блокировки, модерация, правила и приватность.
6. **Нет принуждения.** Камера не обязательна; можно слушать, выйти и не сохранять контакты.

## Первый пользовательский путь

1. Совершеннолетний участник выбирает псевдоним, язык, интересы и принимает правила.
2. Выбирает «Компания» или «Вечеринка», интересующую тему и временной слот.
3. Видит **реальное** состояние набора и честное ожидание, без фальшивых счётчиков.
4. Попадает в текстовую комнату на 4–6 участников. Короткий «импульс» помогает разговору начаться.
5. После успешного альфа-теста добавляется голос с отдельным согласием.
6. Контакт сохраняется только при **взаимном** подтверждении.

## Границы закрытого MVP

**Включено:** Web/PWA, профиль-псевдоним и age gate, тематические комнаты по расписанию, очередь, добровольный режим сбалансированной компании, текст, импульсы, жалобы/блокировки, админ-модерация и метрики. Голос — на втором этапе закрытой беты.

**Исключено:** случайная видеорулетка, бесконечная лента, публичный рейтинг людей, платные сообщения/подарки, массовые вечеринки, точная геолокация, встречи в частных квартирах, свободные личные сообщения от незнакомцев, боты под видом людей.

## Целевая архитектура (пока план)

- **Web:** React + TypeScript + Vite, PWA.
- **API:** NestJS, PostgreSQL + Prisma, Redis, Socket.IO.
- **Voice (позже):** LiveKit Cloud за feature flag; без записи по умолчанию.
- **Android (позже):** Expo / React Native после теста Web/PWA.
- **Среды:** Docker Compose локально, staging, production с мониторингом и резервным копированием.

## Что можно запустить прямо сейчас

Откройте `prototype/index.html` браузером. **Всё на экране — демонстрация, а не действующие комнаты или живые пользователи.**

Для тестов алгоритма понадобится Node.js 20+:

```bash
node --test spikes/matchmaker.test.mjs
node spikes/demo.mjs
```

## Критерий первой беты

100–300 реальных тестировщиков 18+, одна языковая когорта, модераторы и организованные события по расписанию. Смотрим на качество разговоров, ожидание, D1/D7, взаимные контакты, жалобы и удовлетворённость разных групп. Формулы и цели: `docs/METRICS.md`.

## Политики, право, лицензии

Apple особо ограничивает случайные/анонимные чаты и «Chatroulette-style» приложения, Google Play требует возрастных ограничений для ряда подобных форматов. **Именно поэтому MVP — тематические групповые события, а не анонимная рулетка.** Перед запуском необходимы юридическая проверка, актуальные privacy/terms, поддержка и модерация. Источники в `docs/RESEARCH.md`.

Конкурентные механики можно переосмысливать, **но нельзя копировать исходники, графику, название или защищённый интерфейс**. Лицензия на собственный код пока не выбрана — не воспринимайте публичность репозитория как автоматическое разрешение на переиспользование.

**Статус:** концепция + документы + прототип. Следующий шаг — [первый спринт](docs/CODEX_FIRST_SPRINT.md).
