# PULSE — люди без масок

> **Версия концепции: v0.2 (21 октября 2026).** PULSE — близкий по функциональной модели аналог Litmatch, с собственным кодом, дизайном, брендом и принципами безопасности. **Реального backend/онлайн-сервиса пока нет.** В репозитории находятся документы, автономный прототип прежней идеи и экспериментальные тесты матчинга.

**PULSE** — социальное приложение 18+ против скуки и изоляции. Зашёл → выбрал текстовый диалог, голос или вечеринку → встретил реальных людей → при обоюдном желании остался на связи. Позже — безопасные публичные прогулки и встречи.

**Главный продуктовый референс:** [Litmatch в Google Play](https://play.google.com/store/apps/details?id=com.litatom.app). Он предлагает Soul Game (текст), Voice Game (краткий голосовой контакт), Party Chat, Feed и аватары. Мы воспроизводим **категории пользовательских действий**, не торговые названия, чужой интерфейс, исходный код, графику или бренд. Полный разбор: [docs/LITMATCH_FEATURE_MATRIX.md](docs/LITMATCH_FEATURE_MATRIX.md).

## 5 ключевых экранов PULSE

| Раздел | Для чего | Очерёдность |
|---|---|---|
| **Text Match** | Быстрый взаимно подтверждённый текстовый разговор с незнакомцем, с подсказкой для начала | P0: первая реальная вертикаль |
| **Voice Match** | Короткий приватный голосовой контакт после явного согласия | P1: после модерации и нагрузочных тестов |
| **Party Rooms** | Маленькие текстовые/голосовые компании, микрофон по очереди, темы и игры | P1: текстовые комнаты раньше голоса |
| **Avatar / Connections** | Псевдоним, собственный аватар, взаимные связи без открытых DM от незнакомцев | База P0, расширение P1 |
| **Moments** | Короткие публикации о настроении и интересах, с премодерацией/репортами | P2: после проверки безопасности UGC |

**PULSE Outings** (публичные прогулки, кофе, встречи) — P3, после проверки удержания и отдельной программы безопасности.

## Продуктовые принципы

1. **Анонимность перед людьми, ответственность перед сервисом.** Псевдоним и абстрактный аватар, без обязательной фотографии. Возрастной доступ 18+; соответствие законам и требованиям магазинов должно быть реализовано до публичной беты.
2. **Без торговли вниманием.** Нет платных личных сообщений, платного выбора пола собеседника, подарков за деньги, выкупа приоритета в очереди или рейтингов красоты.
3. **Взаимное согласие.** После короткого Text/Voice Match чат продолжается в контактах только после двустороннего согласия; блокировка и жалоба доступны всегда.
4. **Прозрачные очереди.** Никогда не выдаём ботов за людей или несуществующих пользователей за «онлайн».
5. **Равноправие и добровольный баланс.** Сбалансированные 2/2 и 3/3 комнаты — отдельный opt-in, если хватает участников; общие комнаты доступны всем. Глобальный 50/50 не гарантируем.
6. **Безопасность раньше роста.** Антиспам, age gate, жалобы, блокировки, модераторы, журнал действий и право удаления аккаунта.
7. **Нет обязательной камеры, показной роскоши или гонки за подписчиками.** Деньги/внешность не определяют доступ к общению.

## Первый пользовательский сценарий

1. Запуск, возрастной доступ, правила, регистрация, язык и псевдоним.
2. Одна большая кнопка **«Найти собеседника» (Text Match)** + рядом Party Rooms, Voice Match (если включено).
3. Проверка допуска/банов/блокировок, выбор подходящего собеседника, честное ожидание.
4. Взаимно подтверждённый **короткий текстовый диалог**, можно пропустить стартовый вопрос и сразу выйти/пожаловаться.
5. По окончании — «Продолжить общаться?»; только два «Да» создают взаимный контакт.
6. При нехватке людей — добровольный переход в тематическую комнату или запись на ближайший активный вечер.

## Что реально существует сегодня

- `apps/web` — React/TypeScript интерфейс локальной alpha: onboarding-профиль, честное ожидание, handshake, приватный чат, жалоба/блокировка, взаимные контакты и профиль.
- `apps/api` — NestJS REST/Socket.IO API, Prisma/PostgreSQL очередь Text Match, серверный допуск, безопасность, взаимные контакты и модераторские API.
- `packages/contracts` — общие схемы валидации; `infra/compose.yaml` — локальные PostgreSQL и Redis; `.github/workflows/ci.yml` — CI.
- `spikes/matchmaker.mjs` и `prototype/index.html` остаются историческими исследовательскими артефактами.

Это рабочая **локальная alpha**, а не публичный сервис. Логин доступен только двум синтетическим тестовым пользователям в dev/test. Реальная регистрация и провайдер проверки возраста не подключены, поэтому production запуск закрыт.

## Локальный запуск

Требуются Node.js 22+, pnpm 10+, Docker и Docker Compose.

```sh
cp .env.example .env
docker compose -f infra/compose.yaml up -d
pnpm install --frozen-lockfile
pnpm db:generate
pnpm db:migrate
docker compose -f infra/compose.yaml exec -T postgres createdb -U pulse pulse_test
pnpm dev
```

Откройте `http://localhost:5173` в двух отдельных браузерах/профилях и войдите как «Тестовый взрослый A» и «Тестовый взрослый B». Это synthetic identities только для локальной разработки; они не представляют реальных пользователей. API Swagger доступен на `http://localhost:3000/docs`.

Критические E2E тесты используют только выделенную локальную БД `pulse_test` на `127.0.0.1`; команду запускайте из окружения с соответствующими локальными PostgreSQL/Redis:

```sh
PULSE_TEST_DATABASE_URL='postgresql://pulse:pulse_local_only@127.0.0.1:54329/pulse_test?schema=public' \
DATABASE_URL='postgresql://pulse:pulse_local_only@127.0.0.1:54329/pulse_test?schema=public' \
pnpm --filter @pulse/api exec prisma migrate deploy
PULSE_TEST_DATABASE_URL='postgresql://pulse:pulse_local_only@127.0.0.1:54329/pulse_test?schema=public' pnpm test:e2e
```

Проверки качества: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm --filter @pulse/web build`, `pnpm --filter @pulse/api build`.

## Планируемый стек

React + TypeScript + Vite (PWA); NestJS + Prisma + PostgreSQL; Redis (presence/TTL/очереди); Socket.IO (чат/состояние); LiveKit/WebRTC (голос после отдельной проверки). Android после закрытой Web/PWA беты. iOS — **отдельное решение**, потому что Apple §1.2 особо ограничивает приложения, в основе которых random/anonymous chats; нет гарантии публикации.

## Статус и критерий продвижения

**Сейчас:** локальная сквозная Web/API alpha реализует Text Match и базовые проверки безопасности. До пилота нужны настоящий auth/age provider, политика хранения и удаления, операционная модерация и production hardening. Только затем Voice Match, Party Rooms и Android. Первые 100–300 тестировщиков 18+, одна плотная языковая когорта, измеряем время до реального диалога, качество, D1/D7, жалобы и себестоимость.

Мы не копируем чужую интеллектуальную собственность и не утверждаем, что само описание концепции означает готовность к App Store/Google Play. Проверять актуальные требования и проводить юридический review обязательно.
